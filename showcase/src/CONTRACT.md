# Showcase module contract

All modules are concatenated into one offline HTML; no imports/network/dependencies. Root owns core.js, CSS, shell/build/controller, student/admin screens and shared integration. Workers own only their assigned module and targeted check file. No worker commits or edits original/archive/shared files.

`window.WB.reg('S17','Grading workspace','Instructor / TA',(s,h)=>html)` registers pure rendering. `WB.actions['action-name']=(s,p)=>({message?,go?})` mutates only intentional demo data; returns optional navigation and useful state message. Action names must be unique/prefixed. `WB.defineState('teaching',{...})` adds module defaults without replacing root assessment/assignment/submission/institution. Reset clones all defaults. Render must never mutate; WB.render checks this.

Read core.js for exact seeds. Canonical assessment uses marks keyed by person id with five score numbers; question maxima `[6,4,6,8,6]`, question ids `1a,1b,2,3,4`. `assessment.graded` and `released` are person-ID arrays. `WB.score(s,id)` sums. `WB.received(s)` computes received submissions (Aisha uses shared submission.status). `submission.status` is `received` initially; J1 reset explicitly prepares a draft. pages `{id,tag,rotation}`. Faculty and student feedback must share these records. `WB.audit(s,text)` adds a fictional audit entry. `institution.aiEnabled` is false initially; optional draft helper must respect it.

Helpers: `h.e(value)`, `icon(name)`, `btn(label,action,data={},kind='secondary')` (kinds primary/secondary/quiet/danger), `go(label,screenId,kind)`, `pill(text,tone)` (neutral/success/warning/error/info), `head(title,sub,toolsHTML)`, `card(title,bodyHTML,extraClass)`, `row(title,sub,tailHTML)`, `notice(title,body,tone)`, `stats([[value,label]])`, `field(label,'namespace.path',value,type)`, `area(...)`, `select(label,path,value,options)` options strings or `[value,label]`, `table(caption,headersHTML,rowsHTML)`, `tabs([[value,label]],path,current)`, `paper(questionId,rotation)`. Values passed as body HTML must be escaped with `h.e`; safe static markup is fine. Ordinary field changes update data-bind path. No dynamic eval or untrusted links.

Buttons provide `data-action`, params in dataset. Controller invokes actions with state and element.dataset. h.go/go return screen destinations handled by root. Return `{go:'S18',message:'Preview updated.'}` for transitions. All action controls have real local behavior; no fake external calls or sole toast without relevant state change. Dialog/details preferable native. No timers needed.

Available CSS utilities: `.columns` two balanced columns, `.columns.wide-left` work+rubric, `.stack`, `.actions`, `.card`, `.item-row`, `.muted`, `.small`, `.course-tag`, `.form-grid`, `.notice`, `.stats`, `.table-scroll`, `.segmented`, `.check-row`, `.empty`, `.timeline`, `.timeline-item`, `.progress-track`, `.paper-wrap`, `.rubric-item`, `.schedule-grid`, `.room-card`, `.event-card`. Section h4 screen title; h5 card title. All reflow under 760px. Use 14–16px text, no fixed width large canvases, no chart as image.

All people, records and effects fictional. No services/data upload/AI execution, messages, hosting or paid operations. Product boundary and planned trust status must be clear without filling normal task UI with developer language. Read approved docs for source evidence, 40 screens and six journeys. Return workspace evidence and limitations, no recursive delegation.

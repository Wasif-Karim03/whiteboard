# Journey walk, November 2026 (J01–J12)

Date: 15 Nov 2026. **Source review only**: specs, the deep dive and design notes were read; nothing was opened in a browser, on a device or with assistive technology, and no user was involved. All data is fictional. The second walk on the built prototype is Phase 5.

**Method.** Four reviewer subagents (R1–R4), launched in parallel with the Agent tool's model set to `fable`, each walked three journeys as Student, Instructor, TA and Guest, scoring every step against the 12 cross-cutting rules (UX-R01–UX-R12, `research/ux/00_synthesis.md:27-38`), the role-file rules (`01#n`…`05#n`) and Nielsen's 10 heuristics (NH1–NH10), with Nielsen severity 0–4. The builder (Claude Opus 5.5) consolidated: merged the four files, marked duplicates, opened the cited path:line of every severity 3–4 finding before accepting it, and assigned ids ordered by journey, then severity. Models actually used: reviewers `fable` (as requested in the launch call; the runtime did not report a different model), consolidation Opus 5.5.

**Evidence abbreviations.** DD = `design/reviews/board-deep-dive-2026-11-15.md`; SP = `design/final/spec/pages/` (each spec file has a generated comment on line 1 and the panel HTML on line 2, so spec evidence is cited `:2` with a quoted phrase); BDF = `design/reviews/board-decisions-2026-11-15.md`; PLAN = `design/reviews/final-design-plan-2026-11-15.md`; BOARD = `design/board/Whiteboard-Design-Board-2026-11-04.html`; S02 = `design/final/spec/docs/04-spec-02-navigation-and-permissions.html`; NAV = `design/final/spec/docs/19-navigation-map-navigation-json.html`. Decisions BD9 onward are in `design/final/decisions.md`; tracker rows in `design/final/tracker/fix_tracker.csv`.
